# Archived analysis variants

Files in this directory are retained only for analytical provenance. They were superseded during analysis development and are **not used for any reported manuscript result**.

Current reported workflows are documented in the repository-level `REPRODUCIBILITY.md`.


The `full_period_temporal/` subfolder preserves the original full-period temporal diagnostic scripts used to diagnose the label-baseline issue. Corrected held-out-year-excluded temporal analyses are in `analyses/temporal_transfer/`.
