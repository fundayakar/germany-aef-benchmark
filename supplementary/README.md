# Supplementary material

The journal supplementary file is stored here as `Supplementary_Material.docx` and contains Supplementary Tables S1-S5.

Supplementary Table S5 reports the year-specific evaluation of the primary vegetation spatial-CV out-of-fold predictions and is reproduced by `analyses/year_specific_spatial_cv/veg_year_specific_spatial_cv.py` with output in `results/veg_year_specific_spatial_cv.csv`.

The publication-ready file is maintained alongside the manuscript submission and should be synchronized with the archived Zenodo release.
